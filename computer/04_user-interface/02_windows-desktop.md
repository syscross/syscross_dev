# 윈도우 데스크톱

Windows Desktop

---

컴퓨터가 소수의 연구자와 엔지니어의 전유물에서 전 세계 사무실과 가정의 필수품으로 도약할 수 있었던 결정적 계기는 **그래픽 유저 인터페이스(GUI)**의 보급이었다.

깜빡이는 커서 앞에서 명령어 문법을 외워야만 작동하던 컴퓨터는 일반인에게 거대한 장벽이었다. 이 장벽을 무너뜨린 개념이 바로 **'데스크톱 메타포(Desktop Metaphor)'**다. 1970년대 제록스 PARC의 알토(Alto)에서 싹트고 1984년 애플의 매킨토시가 상용화한 이 발상은, 컴퓨터 내부의 추상적인 파일 시스템과 메모리 연산을 우리가 이미 알고 있는 **'물리적 책상 위'**의 풍경으로 번역해 주었다.

디렉토리는 서류를 담는 '폴더'가 되었고, 실행 파일은 '아이콘'으로 형상화되었으며, 불필요한 데이터를 지우는 일은 '휴지통'에 종이를 구겨 넣는 동작으로 치환되었다. 화면 위에 사각형의 **창(Window)**을 여러 개 띄워 동시에 문서를 보며 계산기를 두드리는 이 WIMP(Window, Icon, Menu, Pointer) 구조는 현대 컴퓨터 인터페이스의 문법 그 자체가 되었다.

## Windows가 세운 표준

이 그래픽 인터페이스를 전 지구적 표준으로 굳힌 주인공은 마이크로소프트의 **Windows**였다.

MS-DOS라는 텍스트 기반 운영체제 위에 얹힌 그래픽 껍데기로 출발한 Windows는, 1990년 Windows 3.1을 거쳐 1995년 **Windows 95**에 이르러 오늘날 우리가 아는 데스크톱 인터페이스의 완성형을 제시했다. 

- **시작 버튼(Start Button)과 작업 표시줄(Taskbar)**: 화면 왼쪽 아래 모서리에 모든 프로그램과 설정의 입구를 배치하고, 하단 바에 현재 열린 창들을 나열해 사용자가 길을 잃지 않게 만든 직관적인 내비게이션.
- **마우스 포인터와 우클릭**: 왼쪽 클릭으로 대상을 선택·실행하고, 오른쪽 클릭으로 상황에 맞는 맥락 메뉴(Context Menu)를 여는 조작 체계.
- **단일한 시각 문법**: 창 우측 상단의 '최소화·최대화·닫기(X)' 버튼, 상단 메뉴 바(파일·편집·보기) 등 모든 응용 프로그램이 동일한 규격 안에서 작동하도록 일관성을 강제했다.

애플이 하드웨어와 소프트웨어를 결합한 폐쇄적 생태계에서 완성도를 높였다면, 마이크로소프트는 수천 개의 하드웨어 제조사가 만든 IBM 호환 PC 위에 Windows를 얹어 보급했다. 그 결과 전 세계 인구의 대다수는 '컴퓨터를 켠다'는 행위를 곧 '윈도우 바탕화면을 마주하는 것'과 동일시하게 되었다.

## 통합된 화면의 힘과 무게

Windows의 데스크톱 모델은 같은 GUI라도 리눅스 생태계와 뚜렷한 대조를 이룬다. 리눅스가 커널과 그래픽 서버(X11, Wayland), 그리고 데스크톱 환경(GNOME, KDE 등)을 분리해 사용자에게 조립의 자유를 주었다면, Windows는 운영체제 제조사가 그래픽 스택부터 기본 탐색기와 제어판까지 단일 체계로 묶어 통제하는 길을 택했다.

수십 년 전의 구식 프로그램도 창 테두리만 유지한 채 최신 OS 위에서 돌아가게 만드는 집요한 하위 호환성과, 어느 PC에 앉아도 똑같은 위치에 있는 '시작 메뉴'의 일관성은 기업과 대중 시장을 장악하는 가장 강력한 무기였다.

마우스와 키보드를 양손에 쥐고 창을 겹쳐 쌓아 가며 작업하는 윈도우 데스크톱은, 개인용 컴퓨터(PC)라는 도구가 도달한 가장 효율적이고 보편적인 작업 공간의 전형으로 남아 있다.
